# Planner x

برنامه‌ریز مطالعه (PWA) — فارسی، تقویم شمسی، ذخیره روی خود دستگاه.

## انتشار روی GitHub Pages
1. همهٔ فایل‌ها را در ریشهٔ مخزن آپلود کنید (index.html کنار بقیه باشد).
2. Settings ← Pages ← Source: Deploy from a branch ← main / (root).
3. بعد از یک دقیقه آدرس سایت فعال می‌شود و در Chrome گزینهٔ نصب ظاهر می‌شود.

برای انتشار نسخهٔ جدید، عدد `V` را در `sw.js` تغییر دهید تا کش قدیمی پاک شود.
